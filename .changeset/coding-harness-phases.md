`coding-harness` copies a phase map to `docs/agents/phases.md` on every write. The order is Plan, Design, Build & Test, Deploy, then Operate & Maintain. Each skill in the repo has one line, and a skill runs only when that line matches the request. Each phase names the decision you keep and the artifact the agent produces. Typing a skill starts it. No skill promotes to production. Writing, teaching, and course exercises sit outside the five phases. A shortened copy is replaced from the template.
